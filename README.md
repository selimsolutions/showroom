# Showroom Auto — AVAVA

A beginner-friendly Angular showroom redesign using the supplied car list and images.

## Run locally

1. Install a supported Node.js version for the Angular version in `package.json`.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npx ng serve`.
5. Open `http://localhost:4200`.

## Angular concepts used

- Standalone components
- Parent/child communication with `@Input()` and `@Output()`
- `@for` / `@if` template control flow
- Basic component classes and arrays
- Angular Router for the single car-detail route (`/car/:id`)
- CSS transitions and keyframe animations

This version does **not** use Angular Signals. The range values are illustrative showcase values for the visual animation and are not verified manufacturer specifications.
